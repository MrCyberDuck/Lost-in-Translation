# Conformance cases

Each case is a folder with `rule.yml`, `events.jsonl` (canonical events, see `harness/events.py`) and `expected.json` (the event ids the Sigma spec says must match). Run one with:

    python -m harness.smoke --wave all --case conformance/<area>/<case>

Folders are grouped by taxonomy area (T1 to T26, see [docs/taxonomy.md](../docs/taxonomy.md)). Expected verdicts are hand-set until the reference evaluator exists (Phase 2); after that they are generated by it.

| Case | Source | What it probes |
| --- | --- | --- |
| `smoke` | hand-written | testbed health only |
| `T1-case/T1-001-upper-image` | hand-written | case-insensitive matching of `endswith` and `contains` |
| `T9-logic/T9-001-whoami-all` | SigmaHQ `c248c896` at r2026-07-01, events from the explainer demo | `all of selection_*` over a list selection, `windash`, case |
| `T5-types/T5-001-eventid-integer` | SigmaHQ `66b6be3d` at r2026-07-01, events from the explainer demo | integer `EventID` against typed and untyped storage |
